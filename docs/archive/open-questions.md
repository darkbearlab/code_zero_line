## 原 design doc 開放問題

### 🟢 3.1 Hub 結構

**決定**:Hades 式門選,但呈現為「**隊員與指揮官對話**」的形式——指揮部不知道前方狀況,由前線隊員回報選項。

**Boon 種類包含但不限於**:
- 指定隊員數值提升
- 獲得額外武器分配給隊員
- 一次性使用技能
- 增援
- Meta 資源

**為什麼 framing 很值得**:解決一個 Hades 沒處理好的問題——Hades 的房間預告是「神知道你前面會遇到什麼」,稍微出戲;這個版本「指揮部不知道、隊員回報」反而符合戰場資訊不對稱,而且自然把「犧牲打」這種前線情報接進來(見 3.3 / N4)。

---

### 🟢 3.2 Meta 進度層次

**決定**:雙情報系統 + 榮譽 + 探索進度。經多輪精修後的最終版本見下方 N3 + N12。

1. **可探索區域 / 探索度**:用「突破口 / 橋頭堡 / 佔領區」三階段標示(不用百分比)。佔領區仍會出現衝突任務,但不再產出情報。**沒有支線區域,主線區域 = 全部區域。**
2. **作戰情報(Combat Intel)**:詳見 N3 / N12。
3. **區域情報(Area Intel)**:詳見 N3 / N12。
4. **榮譽(Honor)**:詳見 N3。

---

### 🟢 3.3 任務類型清單(整合 N4 + N8)

**決定**:

**Run 結構**:多場常規殲滅關 + 1 場最終關。
- **中間關卡**:通常是常規殲滅
- **最終關**:任務類型由攻擊區域佔領情形決定出現比例(常識判斷)

**犧牲打分歧任務**:
- 在 boon 選擇時,隊員回報「前方有預期外的高價值目標」
- 玩家可選擇是否挑戰
- 挑戰成功 → meta 進度,或之後幾個 run 的增益

**佔領區的衝突任務**:
- 即使探索完成,佔領區仍會出現衝突(因衝突未平息)
- 這些就是常規殲滅關卡,不是新任務型

**待決細節(留給 sim 階段)**:
- 各最終關任務型在不同區域狀態下的具體出現比例
- 最終關候選任務型清單(原 doc 候選:Capture / Elimination / Defend / Extract / Assassinate / Sabotage)

### 🟡 6.1 小隊規模

**已決定的部分**:

- 槽數有 RNG,榮譽強化後傾向骰到較多槽數

**待決**:

- 強化等級切點?

### 🟢 6.2 小隊編成方式

**決定**:**玩家不組隊**。每個 run 接手一支前線小隊,小隊組成是從池子逐槽抽出來的。

**玩家視角的轉變**:
- 不是「指揮部規劃者」,而是「被空投到前線的指揮官」
- 跟「指揮部不知道前方狀況、由前線回報 boon」完全合拍——玩家本來就是前線視角
- 跟「無線電靜默終局」也合拍——玩家就是那個跟總部失聯的人

**逐槽抽結構**(A+B 混合):
- **槽數**:有 RNG,榮譽強化後傾向骰到較多槽數
- **每個槽**:有性質類型(officer / regular / specialist),從對應 sub-pool 抽
- **池子內容**:強化後高素質比例提高
- **重抽隊員**:全局升級之一,**花榮譽**(組織性強化)

**例外:特化任務**:
- 暗殺、破壞等需要特定能力的最終關任務,玩家可從池子置換 1-2 個槽
- 配合 N6:run 開始前告訴玩家最終關目標 → 玩家準備對應隊員
- 中間關卡完全不選

---

### 🟢 6.3 死亡懲罰嚴重度(整合 N2)

**決定**:差異化懲罰,不是統一比例。

| 結局 | 作戰情報 | 區域情報 | 榮譽 | 探索進度 |
|---|---|---|---|---|
| 完成 run | ✅ 取得 | ✅ 取得 | ✅ 取得(主要來源) | ✅ 推進 |
| 全滅但有打贏關卡 | ✅ 逐關累積 | ✅ 逐關累積 | ❌ 無 | ❌ 無 |
| 全滅且無打贏關卡 | ❌ 無 | ❌ 無 | ❌ 無 | ❌ 無 |

**核心精神**:絕大多數 meta 進度來自「完成 run」,不是「堆屍」。死亡的真正懲罰是失去 run 完成獎勵這筆大收入。

**情報量**:依各關卡設定而定,不是固定比例。**詳細經濟公式見 N12**。

**設計意涵(提醒給未來實作)**:**完成 run 的獎勵必須遠大於過程中累積的情報**——不然死亡感覺不痛。具體比例 sim 階段調。

---

### 🟢 6.4 首次遊玩體驗

**決定**:第一場 run 是「**偵查部隊突圍回總部**」橋段。

- 幾乎一定能贏(教學設計給予優勢)
- 突圍成功 → 總部決定展開侵攻 → 進入主 campaign
- 同時做到三件事:教學、敘事開場、解釋為什麼「指揮部沒情報」(因為才剛突圍回來)
- 與終局的「無線電靜默」形成敘事對稱(見 N5)

---

### 🟢 6.5 本地多人解鎖時機

**決定**:完成第一個 run 後解鎖。可玩內容包含:
- 已解鎖的全局進度內容
- 在贏過的 run 中出現過的敵人
- **地圖也跟著解鎖**

---

### 🟡 6.6 Run 長度目標

**狀態**:取決於 N1 的攻擊深度級數。

**已知**:玩家在出擊前選攻擊深度,深度決定關卡數。所以 run 長度**不是單一值**而是**範圍**。
- 淺攻擊:1-2 關 → 短 run
- 深攻擊:多關 → 長 run

**待決**:
- 攻擊深度具體分幾級?
- 每級分別對應幾關?
- 是否每級各自有目標時長(例如:淺=10min / 中=20min / 深=40min)?

---

### 🟢 6.7 敘事強度

**決定**:**輕敘事,鉤子充足**。

**已建立的敘事鉤子**:
- 偵查部隊突圍開場(6.4)
- 隊員與指揮官對話的 boon 框架(3.1)
- 戰役設置/解決階段的「沒接任務的人會死」(N9)
- 老兵出擊次數累積(N10)
- 無線電靜默終局(N5)

**設計原則**:**不再增加感情方面的深度**。鉤子已經夠多,讓玩家自己編故事比強行塞文本好。

**決定**:v1 就有。攻擊區域選擇是出擊前 UI 的一部分(見 N1)。

### 🟢 N3. 情報 vs 榮譽的職責劃分

**決定**:三種貨幣,各有明確分工。

| 貨幣 | 主要用途 | 來源 |
|---|---|---|
| **作戰情報** | 戰術知識升級(對付敵人、武器熟悉度、武器改良)、解鎖新敵人類型、解鎖新區域、終局解鎖、終局速通路徑 | 玩家親自打贏(70%) |
| **區域情報** | 解鎖新區域(主要),5:1 兌換作戰情報(備用) | 玩家親自打贏(30%)+ 沒接任務骰贏(全部) |
| **榮譽** | 池子強化(高素質比例)、武器層級(裝備庫擴充)、重抽小隊、任務成功率提升、抽槽數提升 | 完成 run 為主 |

**核心切分原則**:
- **情報** = 玩家視角的知識(打仗學到的)
- **榮譽** = 組織視角的資本(指揮成果換來的)

**老兵成長**:**不收費,自動**(見 N10)。如果收費會讓玩家精算「值不值得保住老兵」,毀掉情感。

### 🟢 N5. 終局戰鬥的解鎖條件與挑戰路徑

**決定**:

**第一步:解鎖**
- 終局是升級選單的**最後一項**(以作戰情報購買)
- 在此之前無法挑戰

**第二步:挑戰路徑**(解鎖後,二選一達成才能進入終局)
- **正規路徑**:**所有主線區域達到「佔領」狀態**
- **速通路徑**:支付作戰情報跳過佔領要求(給 RTS 狂人用)
  - 速通價格設計原則:**比正常推圖到終局所獲得的情報還少**——否則速通是虧的,功能就死了。具體數字 sim 階段調

**第三步:終局戰鬥本身**
- 攻擊區域只有 1 關
- 比平常戰鬥要長
- **無犧牲打 / 無高價值目標**
- **無情報獎勵**(無線電靜默,東西傳不出來)

**為什麼這樣設計**:
- **不會有狂刷終局賺錢的退化玩法**(終局根本不給情報)
- **支線區域不存在**——主線區域 = 全部區域,佔領條件清楚
- **「無線電靜默」一個點解三件事**:封閉終局經濟、解釋戰鬥獨立性、與開場「偵查部隊突圍回總部」形成敘事對稱(情報的流動就是這個 campaign 的起點和終點)

**待決細節**:
- 終局戰鬥失敗後的後果?(普通 run 失敗的同等待遇,還是更嚴酷?)
- 終局打贏後 campaign 結束,還是繼續(類似 Hades 的 epilogue)?

### 🟡 N6. 「最後一關特殊目標」如何告知玩家

**已知關聯**:特化任務時玩家可從池子置換 1-2 個槽(見 6.2)。

**待決**:

- 特殊目標清單有多大?是固定清單 RNG 抽,還是和區域類型強關聯?
- 中間關卡(關 1、關 2)是否也有類似預告,還是只有最終關?

### 🟢 N9. 戰役階段結構

**決定**:每個戰役回合分三階段。

```
[戰役設置階段]
  ├─ 抽出本回合所有可選任務(浮動 3-5 個)
  ├─ 每個任務分配一隊出擊士兵(來自池子)
  ├─ 每個任務顯示成功率(fuzzy:高/中/低)
  └─ 玩家選 1 個接手指揮

[戰術階段]
  └─ 你接手的那一場 → 正常戰鬥流程

[戰役解決階段]
  ├─ 你接手的任務 → 戰鬥結果(隊員命運看戰鬥結束時狀態)
  └─ 你沒接手的任務 → 骰成功率
        ├─ 贏 → 隊員回池(出擊次數+1)+ 玩家獲得區域情報
        ├─ 輸 → 隊員從池中永久移除,無獎勵
```

**任務狀態與隊員命運表**:

| 任務狀態 | 結果 | 隊員命運 | 玩家獎勵 |
|---|---|---|---|
| 接手 + 戰鬥贏 | 戰術勝利 | 看戰鬥結束時狀態,活的回池 | 完整(70% 作戰 + 30% 區域) |
| 接手 + 戰鬥輸 | 戰術失敗 | fuzzy 判定,本來活的也可能沒回來 | 部分(看打贏的關卡) |
| 沒接(放棄) | 任務失敗 | 全員死亡 | 無 |
| 沒接 + 任務骰贏 | 任務成功(對玩家無大獎) | 隊員回池(出擊次數+1) | 區域情報(30% 那份) |
| 沒接 + 任務骰輸 | 任務失敗 | 隊員從池中永久移除 | 無 |

**重要副作用(不需設計、自動產生的情感機制)**:
玩家會學會「**有些任務該被犧牲**」——選一個任務代表放棄保護其他任務的隊員。這個冷酷感很強,而且機制上非常乾淨。Frostpunk 的精神。

**新全局升級「任務成功率」**:可花榮譽強化(提升整體基礎成功率),敘事上代表組織效率提升。

### 🟢 N10. 老兵成長機制

**決定**:**自動、免費、按出擊次數累積**。

- **池子強化(榮譽購買)** = 整體基礎水準上升,新人也不爛
- **老兵成長(自動,跟出擊次數)** = 單個有故事的人變強

兩條並行,**不互斥**:池子強化讓「新人也不爛」,老兵成長讓「跟過你的人特別」。**老兵跟著池子升級會疊加**(機制與情感一致——存活的本來就強,加上池子升級又加一次)。

**機制細節**:
- 出擊次數每 N 次 → 素質 +1(到上限為止)。具體數字 sim 階段調
- **不收費**——情感引擎不能收費
- **池子強化會提升所有池子內的人**(包含老兵)

**UI 顯示**:
- v1:純數字,「曾出擊 N 次」
- 任務名單上,曾跟隨玩家的隊員會 highlight(玩家會自編故事)
- 階級系統、戰績紀錄等可後期再加

**戰死老兵的處理**:
- v1:run 結算殺報名單,老兵(出擊次數高)特別標示
- 計分表那層後面再加

### 🟢 N11. 池子規模與替換策略

**決定(2026-04-30 修正)**:**池子目標 30 人,主動補員**。

之前以為「沒接任務 + 失敗 = 永久死亡」是自然汰換、不需補員 — 實作後發現會單調下沉。改為:

- 池子目標 30,補員時機 = 新戰役 + 每場結束
- 角色 floor = 3 officer / 8 specialist / 19 regular(approx 1:3:7);officer floor 確保每個任務都有得抽
- 候補來源:bundled templates seeded random
- 補到 30 為止;不會超過 30(若初始 > 30 也不縮)

詳見 `src/campaign/recruit.ts`、design-summary §4.2。

---

### 🟢 N12. 情報雙貨幣系統

**決定**:**作戰情報 / 區域情報** 雙貨幣。

**經濟公式**:
```
任務基底情報 = 任務類型基底值 × 難度倍率(攻擊強度)

玩家親自打贏:
  作戰情報 = 任務基底情報 × 70%
  區域情報 = 任務基底情報 × 30%

沒接的任務骰贏:
  作戰情報 = 0
  區域情報 = 任務基底情報 × 30%(只拿「30% 那份」)
```

**世界觀解讀**:
- **「30% 區域情報」是世界本身產的**(任務被完成就有,不管玩家在不在)
- **「70% 作戰情報」是玩家親自參與才產的**——完全符合「玩家是世界中唯一在做事的人」的世界觀

**用途分工**:
| 用途 | 作戰情報 | 區域情報 |
|---|---|---|
| 戰術知識升級(對付敵人、武器熟悉度、武器改良) | ✅ | ❌ |
| 解鎖新敵人類型 | ✅ | ❌ |
| 解鎖新區域 | ✅ | ✅(主要用途) |
| 終局解鎖 | ✅ | ❌ |
| 終局速通路徑 | ✅ | ❌ |

**兌換**:
- **區域情報 → 作戰情報 5:1**,單向
- 反向不需要(作戰情報能買所有東西)

**任務類型基底值**:之後 sim 階段調的數字,現在不需要定具體數字。
